Three frontend directions

Each file contains seven surfaces: landing, sign-in, watchlist, empty state, catalog search, alerts & account settings, and a mobile pair showing the seat-open moment.

DIRECTION A
Reading Room

Bookish and calm. Plaster ground, ink serif headlines, hairline rules instead of cards, one oxblood accent. Reads like a printed course register — the most obviously trustworthy of the three.
DIRECTION B
Instrument

A dark monitoring console. Amber LEDs, mono readouts, live poll ticker and an event log. Honest about what the backend actually is — a poller that fires alerts.
DIRECTION C
Signage

Campus-flyer energy. Chrome yellow, heavy ink rules, offset shadows, oversized numerals. The loudest and most student-feeling — highest personality, still legible and simple.
